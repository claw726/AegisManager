# As a task assigner, I want to create and edit tasks, including the title, text, priority, or due date.- Test Plan

## Test Case 1: Verify task assigners can edit tasks.
1. Log in as the task assigner.
2. Navigate to the To-Do List
3. Navigate to a task
4. Verify task has edit button.
5. Edit task
6. Navigate to the To-Do List
7. Verify task has new details

## Test Case 2: Verify task assigners can create tasks.
1. Log in as the task assigner.
2. Navigate to the To-Do List
3. Create to a task
4. Add details in Create Task Form
6. Navigate to the To-Do List
7. Verify new task exists.
