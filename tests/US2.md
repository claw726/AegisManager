# As a task assignee, I would like to update the completion status of my individual tasks.  - Test Plan

## Test Case 1: Verify tasks can be marked complete.
1. Log in as the task assignee
2. Navigate to the To-Do List
3. Navigate to a task
4. Click on Mark Complete. 
5. Verify task is marked complete on To-Do List.

## Test Case 2: Verify Completed Tasks are greyed out.
1. Log in as the task assignee
2. Navigate to the To-Do List
3. Navigate to a completed task.
4. Verify the completed task details are greyed out.

## Test Case 3: Verify Completed Tasks are greyed out for everyone.
1. Log in as the task assignee
2. Navigate to the To-Do List
3. Navigate to a completed task.
4. Verify the completed task details are greyed out.
5. Log in as another task assignee.
6. Navigate to the same assigned task. 
7. Make sure task details are greyed out.

## Test Case 4: Verify Completed Tasks are not viewed inside a project.
1. Log in as the task assignee
2. Navigate to a Project
3. Verify only incomplete tasks are visible.
