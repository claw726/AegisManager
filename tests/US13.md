# Functional Test Plan for 2FA Implementation

## Test Scenarios

Based on the provided acceptance criteria, the following test scenarios have been identified:

1. **Scenario 1: Redirect to 2FA Information Page**
2. **Scenario 2: QR Code Scanning and 2FA Code Entry**
3. **Scenario 3: Saving 2FA Information and Login Prompt**

---

## Detailed Steps for Each Test Scenario

### Scenario 1: Redirect to 2FA Information Page

**Test Steps:**

1. Navigate to the account settings page of the Aegis application.
2. Locate the “enable 2FA” button.
3. Click on the “enable 2FA” button.

**Expected Outcome:**

- The user is redirected to a new page that displays information on how to enable 2FA, including instructions and a QR code.

---

### Scenario 2: QR Code Scanning and 2FA Code Entry

**Test Steps:**

1. Ensure the user is on the 2FA information page.
2. Use a mobile device with an authenticator app installed (e.g., Google Authenticator, Authy).
3. Scan the displayed QR code using the authenticator app.
4. Wait for the authenticator app to generate a 6-digit code.
5. Enter the 6-digit code into the Aegis application.

**Expected Outcome:**

- The Aegis application verifies the entered 6-digit code.
- If the code is correct, the application confirms that the 2FA setup is successful.

---

### Scenario 3: Saving 2FA Information and Login Prompt

**Test Steps:**

1. After successfully entering the correct 6-digit code, check the user’s 2FA settings in the Aegis application.
2. Log out of the Aegis application.
3. Attempt to log back into the Aegis application.
4. Enter the username and password when prompted.
5. After successful login, observe if the application prompts for the 6-digit 2FA code.

**Expected Outcome:**

- The user’s 2FA information is saved.
- Upon logging in, the user is prompted to enter the 6-digit code generated by their authenticator app.

---

## Summary

This functional test plan outlines the necessary steps to validate the implementation of the 2FA feature in the Aegis application. Each scenario is designed to ensure that the user experience is seamless and that the security feature functions as intended.
