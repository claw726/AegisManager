# Task View Switching - Functional Test Plan

## Test Case 1: View Switch UI Display

1. Log in as an account holder
2. Navigate to the homepage
3. Verify that options for switching views are visible, with buttons labeled:
   - "To-Do List View"
   - "Kanban Board View"
4. Verify each button is clearly labeled, styled, and aligned consistently with the UI
5. Click each view button to verify button state updates to active when selected
6. Verify that only one view option is active at a time

## Test Case 2: To-Do List View Content

1. Log in as an account holder with multiple tasks
2. Navigate to the homepage
3. Select "To-Do List View" option
4. Verify:
   - Tasks are displayed in a list format
   - Each task item shows details including:
     - Task description
     - Task assigner
     - Due date
5. Confirm all tasks are visible regardless of their completion status (e.g., incomplete or complete)
6. Confirm list view is styled consistently with the overall UI

## Test Case 3: Kanban Board View Content

1. Log in as an account holder with tasks in various states (incomplete or complete)
2. Navigate to the homepage
3. Select "Kanban Board View" option
4. Verify:
   - Kanban board displays three columns:
     - "Incomplete"
     - "Complete"
   - Each task is placed in the correct column based on its status
5. Confirm task items display key details (e.g., description) within each column
6. Verify column layout and card styling are consistent with the UI

## Test Case 4: Switching from To-Do List View to Kanban Board View

1. Log in as an account holder
2. Navigate to the homepage
3. Ensure "To-Do List View" is selected
4. Click "Kanban Board View" option
5. Verify:
   - The UI switches from list format to Kanban board layout
   - Tasks are correctly divided across the three Kanban columns based on their status
6. Confirm no loss of task data or layout issues occur during the switch

## Test Case 5: Switching from Kanban Board View to To-Do List View

1. Log in as an account holder
2. Navigate to the homepage
3. Ensure "Kanban Board View" is selected
4. Click "To-Do List View" option
5. Verify:
   - The UI switches from Kanban board layout to list format
   - All tasks are displayed in a list with appropriate details (description, assigner, due date)
6. Confirm no loss of task data or layout issues occur during the switch

---

## Edge Cases to Test

### View Switching Edge Cases:

1. **Rapid Switching Between Views:**
   - Quickly switch between "To-Do List View" and "Kanban Board View"
   - Verify the UI correctly transitions without lag or display errors
   - Ensure data remains intact and displayed correctly after rapid switching

2. **Switching Views with Large Number of Tasks:**
   - Populate account with a large number of tasks
   - Switch between views to verify performance, data integrity, and UI responsiveness
   - Confirm task lists or Kanban columns load without delay

3. **Incomplete Data Handling:**
   - Attempt to switch views with incomplete task details (e.g., missing description or due date)
   - Verify the UI displays tasks consistently without breaking or data loss
   - Confirm missing fields are handled gracefully in both views

4. **Filter/Sort State Persistence Across Views:**
   - Apply a filter or sort to the task list
   - Switch between views
   - Verify that the selected filter or sort state is maintained, or the view resets clearly and intentionally

5. **Network Conditions:**
   - Test switching views with a slow connection
   - Simulate connection loss during view switch
   - Verify proper error handling and feedback to the user
