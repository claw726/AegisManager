# Task Sorting and Filtering - Functional Test Plan

## Test Case 1: Sorting UI Display

1. Log in as an account holder
2. Navigate to the homepage
3. Verify sorting options are visible with buttons for:
   - Alphabetical (A-Z, Z-A)
   - Urgency
4. Verify each button is clearly labeled and styled
5. Click each sorting option and verify button state updates to active for the selected option
6. Verify buttons are aligned properly within the UI

## Test Case 2: Search Bar for Filtering Tasks

1. Log in as an account holder
2. Navigate to the homepage
3. Verify the search bar is visible and labeled for filtering by:
   - Task assigner
   - Parent project
   - Parent organization
4. Enter text in the search bar and verify input is registered
5. Verify the search bar is styled consistently with the rest of the UI
6. Confirm the search bar can be cleared by:
   - Clicking a "clear" button (if present)
   - Manually deleting text

## Test Case 3: Sorting Tasks Alphabetically

1. Log in as an account holder with multiple tasks

5. Select "Z-A" sorting option

   - Tasks appear in reverse alphabetical order (Z-A)

## Edge Cases to Test

### Sorting Edge Cases:

1. **Mixed Case and Special Characters:**
   - Test alphabetical sorting with tasks that contain mixed cases (e.g., "alpha", "Alpha")
   - Verify special characters (e.g., @, #) appear in the correct order

2. **Duplicate Sorting Options:**
   - Select the same sorting option multiple times
   - Verify the state remains consistent without unintended effects

3. **Sorting with Existing Filter Applied:**
   - Apply a filter and then change sorting order
   - Verify the filter and sorting work together as expected

### Filtering/Search Edge Cases:

1. **Invalid or Empty Search Criteria:**
   - Enter an invalid character sequence in the search bar
   - Verify no results display if criteria do not match
   - Clear the search and verify all tasks reappear

2. **Rapid Filter Changes:**
   - Quickly enter and delete search terms
   - Verify the system updates without lag or freezing

3. **Filter with Empty Task List:**
   - Apply a filter when there are no tasks in the list
   - Confirm “No tasks found” message displays correctly

### General Edge Cases:

1. **Network Conditions:**
   - Test sorting and filtering with a slow connection
   - Simulate connection loss during filtering/sorting
   - Verify error handling and proper feedback to the user

2. **Session Expiration:**
   - Test filtering and sorting with an expired session
   - Verify re-authentication prompts appear as expected

3. **Data Consistency:**
   - Verify task list refreshes correctly after applying/removing filters
   - Confirm task count updates accordingly
