# Account Info Update - Functional Test Plan

## Test Case 1: Account Update UI Display

1. Log in as a user.
2. Navigate to the account settings page.
3. Verify that the update account info form is visible, including fields for:
    - Email
    - Name
    - Profile Picture
4. Ensure each input field is clearly labeled and styled consistently with the UI.
5. Verify that a submit button is present and enabled.

## Test Case 2: Valid Account Update

1. Log in as a user.
2. Navigate to the account settings page.
3. Enter valid data in all fields:
    - Email: `test@example.com`
    - Name: `John Doe`
    - Profile Picture: Upload a valid image file (e.g., .jpg, .png).
4. Click the submit button.
5. Verify that the system saves the updated account information.
6. Confirm that a success message is displayed indicating the account information has been updated.
7. Log out and log back in to verify that the changes are reflected in the user profile.

## Test Case 3: Email Format Validation

1. Log in as a user.
2. Navigate to the account settings page.
3. Enter an invalid email format in the email field (e.g., `test@.com`).
4. Leave name and profile picture fields as they were.
5. Click the submit button.
6. Verify that an error message is displayed indicating the email format is invalid.
7. Ensure that no changes are made to the account information.

## Test Case 4: Profile Picture File Type Validation

1. Log in as a user.
2. Navigate to the account settings page.
3. Enter valid data in the email and name fields.
4. Upload an invalid file type for the profile picture (e.g., `.exe`).
5. Click the submit button.
6. Verify that an error message is displayed indicating the file type is unsupported.
7. Ensure that no changes are made to the account information.

## Test Case 5: Confirmation Message Display

1. Log in as a user.
2. Navigate to the account settings page.
3. Enter valid data in all fields:
    - Email: `test@example.com`
    - Name: `John Doe`
    - Profile Picture: Upload a valid image file (e.g., .jpg, .png).
4. Click the submit button.
5. Verify that a confirmation message is displayed stating that the account information has been updated.
6. Ensure that the confirmation message is styled consistently with the UI.
