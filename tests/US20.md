# Project Archiving - Functional Test Plan

## Definition: Project manager - a user that has created  and manages a project.

## Test Case 1: Archiving a Project

1. Log in as a project manager.
2. Navigate to the projects list.
3. Select a project to archive.
4. Click the archive button or option in the project settings.
5. Verify that the project is removed from the projects list.
6. Confirm that a success confirmation message is displayed indicating the project has been archived.

## Test Case 2: Confirmation Message on Archiving

1. Log in as a project manager.
2. Navigate to the projects list.
3. Select a project to archive.
4. Click the archive button or option in the project settings.
5. Verify that there is a confimation message.
6. Ensure that the message appears in a user-friendly manner and does not disrupt the workflow.

## Test Case 3: Viewing Archived Projects

1. Log in as a project manager.
2. Navigate to the archived projects section from the user dashboard.
3. Verify that a list of all previously archived projects is displayed.
4. Confirm that each archived project displays relevant details, including:
    - Project Name
    - Description
5. Click on an archived project to view its details.
6. Ensure that all associated data (e.g., tasks, users, files) remains intact and accessible.

## Test Case 4: Projects List Integrity

1. Log in as a project manager.
2. Navigate to the projects list.
3. Confirm that the list does not include any projects that have been archived.
4. Verify that the projects list accurately reflects the current projects, without any archived projects present.

## Test Case 5: Retrieving Archived Projects

1. Log in as a project manager.
2. Navigate to the archived projects section.
3. Select an archived project.
4. Verify that all associated data (e.g., tasks, users) is accessible within the archived project view.
5. Confirm that users can navigate back to the projects list from the archived projects view without losing their place or data.
